# 相交链表

## 题意
给定两个单链表，返回两个链表的相交节点。如果相交，保证只有一个交点。否则返回空指针即可

## 思路：
![[QQ_1767611345453.png]]
设$A,B$ 两个链表长度分别为$a,b$  ，公共部分长度为$c$

两个指针$p1,p2$先分别指向$A,B$的头结点开始遍历，如果指向空那么再重新从另一个链表开始遍历

那么两个指针遍历的长度分别为$a+(c-b)$,$b+(c-a)$ ，是相等的。由图可知，如果此时指针非空，那么公共节点就是当前节点。反之则没有公共节点

```c++
ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode *p1=headA;
        ListNode *p2=headB;
        while(p1!=p2){
            p1 = (p1==NULL)?headB:p1->next;
            p2 = (p2==NULL)?headA:p2->next;
        }
        return p1;
}
```


# 反转链表

## 题意
给定一个单链表，求出反转后的链表

## 思路
不妨设置两个指针$p1,p2$且$p1->next=p2$

循环遍历链表，先存储$p2$的下一个节点，再让$p2$指向$p1$。

```c++
ListNode* reverseList(ListNode* head) {
        ListNode* x=NULL;ListNode* y=head;
        while(y!=NULL){
            ListNode*tmp=y->next;
            y->next=x;
            x=y;
            y=tmp;
        }
        return x;
    }
```


# 回文链表

## 题意
给定一个单链表，判断其是否是回文链表（就是回文序列）

## 思路
直接把单链表的数放进动态数组里判断回文就好了
```c++
 bool isPalindrome(ListNode* head) {
        vector<int>vec;
        while(head!=nullptr){
            vec.push_back(head->val);
            head=head->next;
        }
        for(int i=0;i<vec.size()/2;i++){
            if(vec[i]!=vec[vec.size()-1-i])return false;
        }
        return true;
    }
```

# 合并两个有序链表

## 题意
给定两个升序单链表，返回一个新升序单链表，由这两个链表的元素组成

## 思路
使用两个指针逐个判断哪个指向的元素更小，就先加哪一个即可

写的可能稍微有点麻烦了，主要要注意空指针问题
```c++
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode *a=list1;
        ListNode *b=list2;
        ListNode *head=nullptr;
        ListNode *p=head;
        for(;a!=nullptr&&b!=nullptr;){
            if(a->val<=b->val){
                if(head==nullptr)head=p=a;
                else {
                    p->next=a;
                    p=p->next;
                }
                a=a->next;
            }else{
                if(head==nullptr)head=p=b;
                else {
                    p->next=b;
                    p=p->next;
                }
                b=b->next;
            }
        }
        for(;a!=nullptr;a=a->next){
            if(head==nullptr){
                head=p=a;
            }else{
                p->next=a;
                p=p->next;
            }
        }
        for(;b!=nullptr;b=b->next){
            if(head==nullptr){
                head=p=b;
            }else{
                p->next=b;
                p=p->next;
            }
        }
        return head;
    }
```
